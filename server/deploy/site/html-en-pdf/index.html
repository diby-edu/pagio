HTML en PDF

Enregistrez une page web ou un fichier HTML en PDF au format A4, pour la garder ou l'imprimer.

GratuitSur Android

Télécharger l'application Android

Disponible dans l'application Android ; la version en ligne arrive bientôt.

Comment faire

  1. Choisissez un fichier HTML ou collez l'adresse d'une page.
  2. Lancez la conversion.
  3. Récupérez le PDF.

Questions fréquentes

Les images de la page sont-elles gardées ?

Oui, la page est mise en PDF telle qu'elle s'affiche.

Quel format de page ?

A4, avec des marges adaptées à l'impression.

HTML en PDF est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.
