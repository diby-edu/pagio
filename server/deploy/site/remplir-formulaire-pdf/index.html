Remplir un formulaire

Remplissez un formulaire PDF (demande, inscription, déclaration) en touchant les champs, puis enregistrez-le.

GratuitSur Android

Télécharger l'application Android

Disponible dans l'application Android ; la version en ligne arrive bientôt.

Comment faire

  1. Choisissez votre PDF.
  2. Réglez les options si besoin.
  3. Enregistrez ou partagez le résultat.

Questions fréquentes

Et si le PDF n'a pas de champs ?

Utilisez Modifier PDF pour écrire où vous voulez.

Puis-je le signer ensuite ?

Oui, avec l'outil Signer PDF.

Remplir un formulaire est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.

Outils proches

  • Modifier PDFAjoutez texte, images, formes, surlignage, dessin et notes.
  • Signer PDFSignature manuscrite, saisie ou enregistrée.
  • Numéros de pageNumérotez les pages : position, format et style au choix.

  • En-tête et pied de pageAjoutez titre, date, nom du fichier et pagination.
  • Remplacer du texteCorrigez un mot ou une phrase visible.
  • Biffer (caviarder)Masquez définitivement des informations sensibles.
