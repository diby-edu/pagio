Compresser PDF

Allégez un PDF trop lourd pour l'envoyer par e-mail, WhatsApp ou sur un site de candidature qui limite la taille.

GratuitSur Android

Télécharger l'application Android

Disponible dans l'application Android ; la version en ligne arrive bientôt.

Comment faire

  1. Choisissez un ou plusieurs PDF.
  2. Réglez l'ordre et les options.
  3. Enregistrez ou partagez le résultat.

Questions fréquentes

Puis-je viser une taille précise (1 Mo, 2 Mo) ?

Oui, choisissez le niveau de compression ; Pagio affiche la taille obtenue.

La qualité baisse-t-elle ?

Le texte reste net ; seules les images sont allégées selon le niveau choisi.

Compresser PDF est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.
