Protéger PDF

Ajoutez un mot de passe à un PDF : sans lui, personne ne peut l'ouvrir. Le fichier est chiffré en AES-256.

GratuitSur AndroidEn ligne

Télécharger l'application Android

Comment faire

  1. Choisissez votre PDF.
  2. Réglez les options si besoin.
  3. Enregistrez ou partagez le résultat.

Questions fréquentes

Et si j'oublie le mot de passe ?

Il ne peut pas être retrouvé : notez-le soigneusement.

Puis-je interdire l'impression ou la copie ?

Oui, des autorisations peuvent être réglées.

Protéger PDF est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.
