Créer un PDF

Créez un PDF vierge, ligné, quadrillé ou à points pour prendre des notes, dessiner ou imprimer une feuille.

GratuitSur Android

Télécharger l'application Android

Disponible dans l'application Android ; la version en ligne arrive bientôt.

Comment faire

  1. Ouvrez l'outil dans l'application.
  2. Suivez les indications à l'écran.
  3. Enregistrez ou partagez le document.

Questions fréquentes

Quels formats de page ?

A4, A5, A3 et Lettre US, en portrait ou paysage.

Puis-je écrire dessus ensuite ?

Oui, ouvrez-le avec l'outil Modifier PDF.

Créer un PDF est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.
