Diviser PDF

Découpez un long PDF en plusieurs fichiers : une partie par chapitre, un fichier toutes les N pages, ou des fichiers sous une taille maximale.

GratuitSur AndroidEn ligne

Utiliser maintenantTélécharger l'application Android

Comment faire

  1. Choisissez votre PDF.
  2. Réglez les options si besoin.
  3. Enregistrez ou partagez le résultat.

Questions fréquentes

Puis-je obtenir des fichiers de moins de 2 Mo ?

Oui, choisissez le découpage par taille et indiquez la taille maximale.

Le PDF d'origine est-il modifié ?

Non, Pagio crée de nouveaux fichiers et garde l'original intact.

Diviser PDF est-il gratuit ?

Gratuit, avec une limite par jour ; illimité avec Premium.

Mes documents sont-ils en sécurité ?

Oui : la plupart des traitements se font sur votre téléphone ou dans votre navigateur. Quand un document passe par le serveur Pagio, il est effacé juste après.
